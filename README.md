
# Student Study Planner

## Description
Student Study Planner is a simple Python project that helps students create 
and manage a list of study tasks. Users can add tasks, 
view their study list,
and check the total number of tasks.

## Features
- Add study tasks.
- Display all saved tasks.
- Number tasks automatically.
- Count total study tasks.
- Exit the program whenever needed.

## Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## Concepts Learned
- Lists and variables
- User input and output
- `while` loops
- `if` statements and `break`
- List methods (`append()`)
- `enumerate()` and `len()`
- String methods (`lower()`)
